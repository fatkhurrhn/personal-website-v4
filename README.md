My personal portfolio website, forked from [chanhdai.com](https://chanhdai.com) and customized with my own design, content, and features.

→ Live site: [fatkhurrhn.dev](https://fatkhurrhn.dev)

## Overview

### Stack

- Next.js
- Tailwind CSS
- shadcn/ui

### Features

- Clean and responsive design
- Light/Dark themes
- Projects section powered by the GitHub API
- Blog feed powered by DEV.to
- Certificates & badges with image preview
- Floating AI chat widget
- Mobile sidebar navigation
- SEO optimized (JSON-LD, sitemap, robots)
